# 27-Project Curation Matrix & Architectural Synthesis

This document details how **`waflare`** curates and unifies all **27 GitHub repositories** at the intersection of **Cloudflare & WhatsApp** into one clean-room, MIT-licensed, zero-runtime-dependency TypeScript codebase.

> **Clean-Room Licensing Guarantee:** Reference repositories include `MIT`, `Apache-2.0`, `GPL-3.0`, `AGPL-3.0`, custom licenses, and unspecified repos. Every module inside `src/` was engineered from scratch against public protocol specifications (Meta Cloud API v21.0, Twilio Webhooks, MCP JSON-RPC 2.0 `2025-03-26`, Web Crypto, Cloudflare Workers/DO/D1/R2/AI, and Cloudflare Plexi REST API) with zero copyleft code copied.

## Architectural Trade-Offs Resolved in `waflare`

1. **Meta Cloud API vs Linked-Device/Baileys:** Many MCP repos rely solely on Baileys-style linked-device protocols (risking WhatsApp session disconnects), whereas CRM repos rely strictly on Meta Cloud API. `waflare` defaults cleanly to **official Meta Cloud API + Twilio** at the edge while providing **Cloudflare Tunnel Companion APIs (`/api/companion/*`)** for Android/Baileys edge bridges.
2. **Read-Only Privacy vs Read-Write Automation:** `finereli/whatsapp-mcp` enforces read-only access for safety, while `felipeadeildo/whatsapp-mcp` and `spirit122/whatsapp-mcp-server` expose full send/CRM tools. `waflare` supports **both** via a runtime environment switch (`MCP_READ_ONLY=true|false`) and encrypts stored replies with **PBKDF2 + AES-256-GCM**.
3. **Structured `/sql` vs Semantic `/rag`:** Instead of picking one retrieval strategy, `waflare` provides both side-by-side (`src/retrieval/dualRetrieval.ts`), guarding `/sql` against DDL/DML injection while combining BM25 + vector cosine similarity in `/rag`.
4. **Zero-Config Local Portability:** All 27 projects target Cloudflare Workers/D1/DO/AI bindings that normally require cloud provisioning to test. `waflare` uses strictly erasable TypeScript + Web Standard APIs (`crypto.subtle`, `Request`, `Response`, `fetch`), allowing full local execution and automated `node --test` verification with **zero npm runtime dependencies**.
